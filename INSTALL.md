# 📥 Guia de Instalação Completo - Adam FinanceAI

## Requisitos

- Python 3.10+
- Ollama instalado

## Passos Rápidos

1. Instale Ollama: https://ollama.ai
2. Baixe modelo: `ollama pull llama3.1`
3. Inicie Ollama: `ollama serve`
4. Clone projeto e instale dependências:

```bash
cd src
pip install -r requirements.txt
streamlit run app.py
```

Acesse: http://localhost:8501

Veja documentação completa no README.md
